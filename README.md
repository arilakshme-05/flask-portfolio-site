# Flask Portfolio Website

A personal portfolio web application built with Python Flask, featuring static asset management, template rendering, and an interactive contact form.

---

##  Features

* **Flask Routing:** Multi-page navigation (Home, Contact, Projects).
* **Template Rendering:** Dynamic HTML rendering using Jinja2 templates.
* **Interactive Contact Form:** Handles user inquiries using `POST` request routing.
* **Static Asset Handling:** Clean styling and design implemented using custom CSS.

---

## Tech Stack

* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3, Jinja2 Templates

## Setup Instructions
1.**Clone the repository**:
git clone [https://github.com/arilakshme-05/flask-portfolio.git](https://github.com/arilakshme-05/flask-portfolio.git)
cd flask-portfolio

2.Install Flask:
pip install flask

3.Run the application:
python app.py

4.Open in browser:
Navigate to http://127.0.0.1:5000/ in your web browser.
